# Якорь Реальности

> Кампания для Forgotten Realms об исследовании древней сети, разломах между близкими версиями мира и цене спасения цивилизации.

## Если проводишь игру — начни здесь

1. [[06 — Сюжет/Сценарий кампании — Якорь Реальности|Сценарий кампании]] — единый хронологический файл: маршрут, сцены, тексты для игроков, улики и переходы.
2. [[00 — Управление кампанией/Памятка ведущему|Памятка ведущему]] — короткое напоминание о том, что ведущий знает, а что пока раскрыто героям.

Во время игры основной файл — сценарий кампании. Остальные материалы открывай только для справки.

## Справочники ведущего

- [[01 — Мир/Древняя цивилизация/Создатели Якоря|Древняя история]] — основной источник правды о цивилизации и Якоре.
- [[01 — Мир/Аномалии/Аномалии реальности|Аномалии]] — каталог проявлений и их закономерностей.
- [[04 — Фракции/Возможные фракции|Фракции]] — их цели и разногласия.
- [[03 — Персонажи/Возможный соперник-исследователь|Элиас Вейн]] — предварительная заметка о повторяющемся сопернике.
- [[10 — Материалы и референсы/Референс — ложное небо Genshin Impact|Референс Genshin Impact]] — только принцип постепенного раскрытия.

## Управление кампанией — не для игрового стола

- [[00 — Управление кампанией/Утверждённый канон|Утверждённый канон]] — реестр принятых решений.
- [[00 — Управление кампанией/Журнал решений|Журнал решений]] — когда и почему решения были приняты.
- [[00 — Управление кампанией/Открытые вопросы|План разработки]] — детали, нужные для следующих приключений.
- [[06 — Сюжет/Тайны и загадки/Тайна Якоря|Лестница улик]] — скрытая логика раскрытия и резервные подтверждения.

Все заметки предназначены мастеру, пока явно не помечены `доступ: игрокам`. Для игроков показывай только отдельные блоки «Текст для игроков» в сценариях и уликах. Изображения хранятся в [[11 — Иллюстрации/README|папке иллюстраций]].
