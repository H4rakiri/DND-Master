# Иллюстрации кампании

Храни здесь локальные изображения кампании. Для каждой категории используй отдельные папки `Для мастера` и `Для игроков`, чтобы секреты не попадали в раздаточные материалы.

Категории: Персонажи, Локации, Фракции, Артефакты, Аномалии, Карты, Головоломки, История, Референсы.

В заметках используй встраивание Obsidian: `![[Для мастера/Локации/Название.webp|700]]`. Для сторонних изображений записывай источник и лицензию. Предварительные концепты помечай как черновые; картинка сама по себе не устанавливает канон.

Папки создаются по мере появления материалов, без пустых заготовок.
